# Generative Flow Field Art Generator

## Repository



## Description

This project is a generative art tool that creates dynamic visual patterns using flow fields and noise functions. It explores how algorithmic systems can produce aesthetically complex digital artwork.

## Features

1. Flow Field Generation
	- Use Perlin noise or mathematical functions to generate vector fields that guide particle motion.
2. Particle System
	- Simulate particles moving through the flow field to create smooth, organic patterns.
3. Customization Controls
	- Allow users to adjust parameters such as particle count, speed, color, and noise scale.
4. Export Artwork
	- Enable saving generated visuals as images for sharing or further use.

## Challenges

* Learning how to implement Perlin noise or similar algorithms.
* Designing visuals that look artistic rather than random.
* Optimizing performance for rendering many particles smoothly.

## Outcomes

Ideal Outcome:

* A polished generative art tool that produces visually striking and customizable flow-based artwork with user controls and export functionality.

Minimal Viable Outcome:

* A working particle system that follows a basic flow field and generates a visually interesting static or animated pattern.
